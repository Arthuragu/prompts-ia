# 04. Escrever procedimento

## Objetivo
Transformar a solução que funcionou num chamado em um procedimento passo a passo, para outros atendentes repetirem sem depender de quem resolveu. Esse material é a base do assistente do Projeto 2.

## Entrada
Anotações informais do atendente sobre o problema e o que ele fez (casos de [`testes/solucoes-ficticias.md`](../../testes/solucoes-ficticias.md)).

## Saída esperada
Procedimento com: título, quando usar, o que é preciso ter antes, passos numerados, como confirmar que resolveu e quando escalar. Usa só o que está nas anotações. Quando algo não consta, diz isso em vez de inventar. Não repete dados pessoais ou senhas.
